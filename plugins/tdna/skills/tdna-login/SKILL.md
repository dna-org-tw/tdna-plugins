# 登入與重新登入 TDNA

1. 使用者要登入或確認連線時，先嘗試呼叫 TDNA 的 `whoami`。若客戶端要求 OAuth 授權，引導使用者完成其原生連線流程。只有 `whoami` 成功後，才顯示目前帳號與角色並說明已連線。
2. 使用者明確要求重新登入或換帳號時，不要因 `whoami` 成功就結束。使用客戶端提供的 TDNA 重新授權功能；若本次環境沒有可呼叫的連線管理工具，請使用者開啟客戶端的 TDNA 插件／MCP 連線設定，使用畫面上實際提供的登入、重新連線或中斷後連線操作。不要猜測按鈕名稱、捏造深層連結或宣稱已替使用者完成。
3. OAuth 授權頁顯示的帳號不符時，按「重新登入／切換帳號」，選擇正確的 Google 帳號，再按「同意並連接」。此按鈕會清除 TDNA 網站登入狀態並保留此次授權流程，不會自動撤銷其他客戶端的授權。
4. 連線網址是 `https://console.dna.org.tw/mcp`。單獨開啟 `https://console.dna.org.tw/login` 只登入後台，不會完成客戶端 OAuth。不要自行拼湊 OAuth authorize 網址；client_id、state 與 PKCE 由客戶端管理。
5. 重新授權完成後再次呼叫 `whoami`，確認實際帳號與角色。仍遇到 401 時停止循環重試，說明尚未連線；角色不足、未受邀或帳號到期請找管理者，不要用重新登入繞過權限。
6. 不要求使用者貼 token、密碼或 Client Secret，不刪除本機設定，不撤銷其他連線。登入問題不得包含憑證或完整 OAuth URL 的回報。
